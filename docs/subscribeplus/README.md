# 订阅下载增强

`SubscribePlus` 是 MoviePilot V3 插件，用于检查电视剧订阅的已播出缺集，分析未下载原因，并提供人工处理入口。

- 插件 ID：`SubscribePlus`
- 当前版本：`1.1.7`
- 适用版本：MoviePilot `>=3.0.0`
- 运行方式：一个插件、一次扫描全部符合条件的订阅、本轮结果统一汇总展示

## 工作流程

```text
读取全部电视剧订阅
  → 根据媒体身份、季号和 TMDB 播出日期找出缺集
  → 先观察 MoviePilot 原生订阅搜索结果
  → 必要时分析插件配置范围内的其他站点
  → 区分暂无目标集、识别异常、规则拦截和可下载
  → Telegram / 页面展示结果
  → 用户决定重试、搜索其他站点、下载或修改规则
  → 入库后刷新诊断，移除已解决项目
```

插件不会自动删除订阅，也不会自动暂停订阅。普通诊断扫描不会自动下载资源；只有用户在交互中明确选择下载，或启用最终集整季包处理后由对应事件链路执行配置内动作。

## 主要功能

### 1. 电视剧订阅缺集扫描

- 一次扫描全部符合条件的电视剧订阅，不再按数量分批轮转。
- 按 `播出日期 + 宽限天数 <= 当前日期` 判断是否进入诊断。
- 使用规范媒体身份 `media_source + media_id`；旧 TMDB 订阅保留兼容回落。
- 读取订阅起始集、媒体库缓存和整理历史，优先检查近期缺集。
- 支持暂停订阅参与检查。
- 支持按 MoviePilot 电视剧二级分类筛选。

### 2. 复用 MoviePilot 原生订阅搜索

插件优先观察原生订阅搜索结果：

- MP 已找到并接管可匹配资源时，不重复发送插件诊断通知。
- 订阅站点没有目标集时，再按需检查插件配置中的其他站点。
- 罗马音补搜沿用原订阅的站点、季集、包含规则和自定义识别词，不自动扩大范围。

### 3. 诊断未下载原因

诊断结果统一区分：

- `no_pt_resource`：搜索完成，但没有覆盖目标缺失集的资源。
- `recognition_issue`：存在覆盖目标集的资源，但媒体或季集识别不稳定。
- `rule_blocked`：资源识别正确，但被订阅包含规则拦截。
- `downloadable`：存在覆盖目标缺失集且规则通过的候选资源。
- `site_scope_blocked`：订阅站点没有目标集，其他配置站点存在目标集资源。
- `search_failed`：搜索或宿主调用失败。

每次 PT 诊断会记录搜索统计，明确区分：

```text
原始资源数 → 目标季资源数 → 覆盖缺失集资源数 → 识别成功数 → 包含规则通过数
```

因此，“搜索到了资源”不等于“找到了可补缺的资源”。

### 4. 其他站点补充搜索

Telegram 通知或 `/sp` 待处理列表中可以：

- 搜索某个订阅范围之外的站点。
- 搜索全部其他站点。
- 查看目标集候选资源。
- 手动选择并提交下载。

补充搜索不会自动修改原订阅的站点范围。

### 5. 订阅规则建议

插件可以从候选资源中提取制作组和平台关键词，生成订阅包含规则预览：

- 先显示修改预览。
- 用户确认后才写入订阅规则。
- 不把站点 ID 当作制作组或平台规则。
- 可记录规则修改历史。

### 6. Telegram 交互

启用 Telegram 独立通知后，本轮结果会按通知目标统一汇总；用户可以进入单剧详情继续处理。

常用入口：

- `/sp`：查看当前待处理诊断。
- `/ci 媒体文件名`：进入自定义识别词工具。
- `下载`：触发 MP 原生订阅搜索，或打开候选下载选择。
- `搜索其他站点`：临时扩大搜索范围。
- `调整规则`：生成包含规则预览。
- `忽略本次`：在配置的期限内抑制同一诊断提醒。
- `结束`：结束当前交互并尝试删除通知消息。

### 7. 入库后自动收敛

收到转移完成事件后，插件会重新检查诊断结果，已入库的集会从待处理列表中移除，避免继续展示旧缺集。

## 最终集整季包处理

这是订阅链路中的可选维护功能，默认关闭。

启用后，定时主扫描会按完播剧集的最后一集播出日期搜索整季包。命中 MoviePilot `DownloadAdded` 事件后：

- 严格校验电视剧、媒体身份、季号、最终集和整季包范围。
- 可将新 qBittorrent 整季包的全部文件设为下载。
- 按同剧、同季、同保存目录、已完成单集和精确 hash 匹配旧 qBittorrent 单集任务。
- `task` 模式只删除旧 qB 任务。
- `source` 模式由 qB 使用 `delete_file=true` 同时删除旧任务和源文件。
- 不删除媒体库目标文件。
- MV3 只用于按完整源路径补充查询 `processed` 整理记录，不调用 MV3 删除接口，也不是 qB 清理前置条件。

手动扫描和预览保持非破坏性，不会触发下载、qB 删除或 MV3 操作。

## 自定义识别词工具

页面和 `/ci` 支持三种人工操作：

- `AI 识别并写入`：使用 MoviePilot 当前 AI 配置识别媒体身份，经过权威名称和 TMDB 身份门禁后写入。
- `强制绑定`：按文件名、媒体类型和 TMDB ID生成窄范围绑定规则。
- `修正年份`：按 TMDB 首播年份生成季级年份修正规则。

新规则插入 MoviePilot 自定义识别词顶部，并附带维护注释；不会删除旧规则。清除识别历史不会删除已经写入 MoviePilot 的规则。

## 配置说明

### 扫描设置

- `启用插件`：开启 Cron 扫描。
- `宽限天数`：单集播出后等待多少天再诊断。
- `Cron`：扫描周期，例如 `0 */6 * * *`。
- `二级分类`：只检查所选电视剧分类；留空时使用可识别分类。
- `PT搜索范围`：插件补充诊断使用的站点范围；留空使用 MP 默认可搜索站点。

### 通知权限

- `Telegram 独立通知`：发送订阅诊断汇总。
- `允许 TG 修改订阅规则`：允许 Telegram 交互确认写入包含规则。
- `不通知天数`：同一诊断选择忽略后，在指定期限内不重复提醒；`0` 表示关闭抑制。

### 最终集整季包

- `启用最终集整季包处理`：默认关闭。
- `旧 qB 单集任务清理`：关闭、只删任务、删任务及源文件。
- `MV3 网站地址`：可选，仅用于只读查询整理事件。
- `MV3 API Key`：可选，使用 `X-API-Key` 请求头，不使用 Bearer/JWT。
- `测试 MV3 连通性`：只读查询 `GET /api/v1/monitor/events`，不保存配置、不删除数据。

### 候选下载

- `候选缓存天数`：候选下载信息的本地缓存期限，默认 3 天；`0` 表示关闭。
- 插件重载或重启后，如果缓存仍有效，可以重建候选下载上下文。

## 数据和安全边界

- 插件只使用自己的数据目录保存诊断、交互、候选缓存和操作记录。
- 本地 JSON 写入使用临时文件、刷新和原子替换，降低中断导致文件损坏的风险。
- 插件不会因为发现其他站点资源就自动修改原订阅站点。
- 规则修改、候选下载和 qB 删除均有明确入口或配置开关。
- MV3 链路只读查询，不调用删除接口。

## 说明

SubscribePlus 是“订阅缺集诊断和人工处理增强”插件，不替代 MoviePilot 原生订阅系统。资源是否存在、是否能识别、是否符合规则和是否执行下载，分别由对应阶段决定。
