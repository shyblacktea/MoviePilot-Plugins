# 观众站守护者

`AudiencesKeeper` 是专为观众站（`audiences.me`）定制的自动化守护插件。针对观众站频繁出现的 Cloudflare Turnstile 验证及 NexusPHP 搜索防刷限制，利用 MoviePilot 内置的仿真浏览器实现全自动过盾、更新 `cf_clearance` 凭据以及带人机穿透的每日自动签到。

- 插件 ID：`AudiencesKeeper`
- 当前版本：`0.0.6`
- 插件目录：`plugins.v3/audienceskeeper/`
- 适用版本：MoviePilot V3（`>=3.0.0`）
- 作者：`shyblacktea`

## 背景与痛点

1. **Cloudflare 盾（403/503 阻断）**：观众站定期或遇频繁搜索时会要求完成 Turnstile 托管挑战。由于常规下载器或 API 仅发普通 HTTP 请求，无法执行 JS，会导致订阅搜索持续返回空结果或报错。
2. **NexusPHP 搜索防刷频次**：连续搜索后站点提示“搜索人机验证未通过，请返回种子列表页重新进行验证！”，导致搜索死锁。
3. **每日签到带强人机**：观众站签到页面明确要求“验证通过后将自动完成签到”，普通签到插件无法自动打卡。

## 核心功能

- **自动化识别站点**：无需用户繁琐查找站点编号，全量自动匹配观众站（`audiences.me`）。
- **执行周期全面支持**：
  1. 支持 5 位标准 cron 表达式（如 `0 9 * * *`）；
  2. 支持间隔小时与时间范围（如 `2.3/9-23` 表示 9-23 点之间每隔 2.3 小时执行一次）；
  3. 留空默认在 9-23 点之间随机执行 2 次。
- **智能重试与登录保号分离**：
  - 每天首次全量执行（先过盾刷新 Cookie，再签到）；
  - 当日已确认签到成功且 Cookie 正常时自动跳过后续周期重试，杜绝无效频次刷人机；
  - 遇到签到未完成时自动重试；若已检测到有效登录态但签到未完成，会单独记录“登录成功”，确保保号状态明确记录。
- **Telegram 通知智能防刷**：
  - 成功通知每日仅首次推送一次，不重复刷屏；
  - 失败通知支持一键「🔕 今天不再通知」，点击后当日后续重试失败原地静默，次日自动恢复。
- **记录面板平滑滚动**：过盾记录与签到记录表格增加固定高度（320px）与固定吸顶表头，可在卡片内自由纵向滚动查看历史。
- **Turnstile 三策略求解**：iframe 复选框点击 → 真实鼠标坐标点击 → 组件容器点击，最长等待 60 秒。
- **解除搜索防刷限制**：访问种子列表页（`torrents.php`）洗白防刷计数。

## 配置说明

- `启用插件`：插件总开关。
- `发送通知`：任务执行完成后是否发送通知。
- `执行周期`：支持 5 位 cron、间隔小时如 `2.3/9-23`，留空默认 9-23 点随机 2 次。
- `观众站点 ID`：默认 `0` 自动全网识别观众站，无需手动指定。
- `观众站地址`：默认 `https://audiences.me/`。
- `浏览器专用代理`：可选填代理应对机房 IP 被 Cloudflare 风控的场景。
- `保存后立即运行一次`：保存配置后在后台立即执行一次过盾和签到。
- `清空执行历史记录`：开启并保存后一键清空过盾和签到记录。
