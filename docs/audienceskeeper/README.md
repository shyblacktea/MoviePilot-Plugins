# 观众站守护者

`AudiencesKeeper` 是专为观众站（`audiences.me`）定制的自动化守护插件。针对观众站频繁出现的 Cloudflare Turnstile 验证及 NexusPHP 搜索防刷限制，利用 MoviePilot 内置的仿真浏览器实现全自动过盾、更新 `cf_clearance` 凭据以及带人机穿透的每日自动签到。

- 插件 ID：`AudiencesKeeper`
- 当前版本：`0.0.6`
- 插件目录：`plugins.v3/audienceskeeper/`
- 适用版本：MoviePilot V3（`>=3.0.0`）
- 作者：`shyblacktea`

## 背景与痛点

1. **Cloudflare 盾（403/503 阻断）**：观众站定期或遇频繁搜索时会要求完成 Turnstile 托管挑战。由于常规下载器或 API 仅发普通 HTTP 请求，无法执行 JS，会导致订阅搜索持续返回空结果或报错。
2. **NexusPHP 搜索防刷频次**：连续搜索后站点提示“搜索人机验证未通过，请返回种子列表页重新进行验证！”，导致搜索死锁。
3. **每日签到带强人机**：观众站签到页面明确要求“验证通过后将自动完成签到”，普通签到插件无法自动打卡。

## 核心功能

- **自动化识别站点**：无需用户繁琐查找站点编号，全量自动匹配观众站（`audiences.me`）。
- **自动化过 CF 盾并续期 Cookie**：定时唤起带有反指纹特性的仿真浏览器访问观众站，自动通过 Turnstile 挑战并抓取最新的 `cf_clearance` 凭证与真实 UA，直接热更新写回 MoviePilot 数据库。
- **解除搜索防刷限制**：过盾过程中自动加载种子列表页（`torrents.php`），顺带重置站点的搜索防刷计数。
- **全自动穿透人机签到**：模拟点击签到页面的 Turnstile 复选框，自动领取每日爆米花奖励，多重关键字智能识别防漏签。
- **状态看板与一键操作**：内置卡片展示今日签到状态、Cookie 长度与 CF 凭据有效性，支持手动一键执行签到与过盾刷新。
- **消息推送通知**：通过 Telegram / 设定渠道实时通报签到结果与 Cookie 续期状态。

## 配置说明

- `启用插件`：插件总开关。
- `发送通知`：任务执行完成后是否发送通知。
- `观众站点 ID`：默认 `0` 自动全网识别观众站，无需手动指定。
- `观众站地址`：默认 `https://audiences.me/`。
- `启用自动每日签到`：开启定时自动签到。
- `每日签到时间 (Cron)`：默认 `0 9 * * *`（每天 09:00）。
- `启用自动过盾与洗白搜索`：开启定时防刷洗白与过盾。
- `过盾与洗白周期 (Cron)`：默认 `0 */2 * * *`（每 2 小时一次）。
- `保存后立即运行一次`：保存配置后在后台立即执行一次过盾和签到。

## 版本记录

### v0.0.6

- 自动识别观众站点，无需手动填写站点 ID。
- Turnstile 求解三策略：iframe 复选框点击 → 真实鼠标坐标点击 → 组件容器点击，最长等待 60 秒；失败诊断可区分「出口 IP 被 Cloudflare 风控」「组件未渲染」「未下发令牌」。
- 健壮导航：`commit` 优先 + DOM 软等待 + 3 轮重试，并屏蔽图片/字体/媒体资源，页面 3~4 秒载入。
- 签到结果严格按 DOM 卡片状态（成功图标 / 今天已签到 / 顶部打卡标记）判定，杜绝静态规则文本造成的假成功。
- 过盾记录与签到记录分栏展示，标题旁可一键清空。
- 通知内联按钮：签到附「🔁 重新签到 / 🛡️ 刷新CF盾」，过盾附「🛡️ 重新过盾 / 📅 立即签到」，点击后原消息原地刷新结果。
- 可选浏览器专用代理，应对机房 IP 被 Cloudflare 风控的场景。
