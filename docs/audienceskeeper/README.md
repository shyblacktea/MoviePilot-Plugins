# 人人人守护者

`AudiencesKeeper` 是专为人人人定制的自动化守护插件。针对频繁出现的 Cloudflare Turnstile 验证及 NexusPHP 搜索防刷限制，利用 MoviePilot 内置的仿真浏览器实现全自动过盾、更新 `cf_clearance` 凭据并洗白搜索防刷计数。

> 站点已于 2026-10 下线签到页（`attendance.php` 返回 404），本插件自 `v0.0.9` 起**移除全部签到功能**，只保留过盾与 Cookie 维护。

- 插件 ID：`AudiencesKeeper`
- 当前版本：`0.0.9`
- 插件目录：`plugins.v3/audienceskeeper/`
- 适用版本：MoviePilot V3（`>=3.0.0`）
- 作者：`shyblacktea`

## 背景与痛点

1. **Cloudflare 盾（403/503 阻断）**：定期或遇频繁搜索时会要求完成 Turnstile 托管挑战。由于常规下载器或 API 仅发普通 HTTP 请求，无法执行 JS，会导致订阅搜索持续返回空结果或报错。
2. **NexusPHP 搜索防刷频次**：连续搜索后站点提示“搜索人机验证未通过，请返回种子列表页重新进行验证！”，导致搜索死锁。

## 核心功能

- **自动化全量识别**：无需手动输入站点 ID 或地址，自动匹配识别对应站点。
- **过盾与洗白独立周期**：支持自定义周期（默认 `0 */2 * * *` 每 2 小时一次），定期访问列表页保持 Cookie 有效并重置搜索防刷频次。
  - 支持 5 位 cron 表达式；
  - 支持间隔小时与时间范围（如 `2.3/9-23` 表示 9-23 点之间每隔 2.3 小时执行一次）；
  - 留空默认每 2 小时。
- **Cookie 与 UA 热更新**：过盾成功后把浏览器上下文里的全部 Cookie（含 `cf_clearance`）与真实 UA 直接写回 MoviePilot 站点配置，无需手动复制。
- **Telegram 通知智能防刷**：
  - 成功通知每日仅首次推送一次，不重复刷屏；
  - 失败通知支持一键「🔕 今天不再通知」，点击后当日后续重试失败原地静默，次日自动恢复。
- **记录面板平滑滚动与异步清空**：表格固定高度（320px）与吸顶表头，可在卡片内自由纵向滚动；清空记录采用 MoviePilot 原生异步事件，点击不跳转页面。
- **Turnstile 三策略求解**：iframe 复选框点击 → 真实鼠标坐标点击 → 组件容器点击，最长等待 60 秒。

## 配置说明

- `启用插件`：插件总开关。
- `发送通知`：任务执行完成后是否发送通知。
- `启用过盾与洗白搜索`：开启定期防刷洗白与过盾。
- `过盾与洗白执行周期`：默认每 2 小时执行一次（`0 */2 * * *`），可自定义。
- `保存后立即运行一次`：保存配置后在后台立即执行一次过盾。
- `清空执行历史记录`：开启并保存后一键清空过盾记录。

## 远程命令

- `/audiences_cookie`：立即模拟过 CF 盾并刷新人人人 Cookie。
