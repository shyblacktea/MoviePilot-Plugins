# 我就想通知到群组！

`NotifyToGroupShy` 是 MoviePilot V3 插件，用于独立管理系统通知目标和订阅用户通知映射。

## 主要功能

- 管理资源入库、资源下载、添加订阅/订阅完成的系统通知目标。
- 管理订阅用户通知映射，支持按通知目标投递。
- 直接在同一配置页面内维护两节通知设置，不依赖 SubscribePlus 的旧面板。
