# 清理无效插件

## 核心用途

> [!NOTE]
> 用于处理 MoviePilot 已安装插件列表中残留但无法加载的记录，支持扫描、清理和重新安装。

#### **无效插件扫描**

- 扫描数据库中残留但无法加载的插件记录。
- 显示运行目录、本地插件源和异常状态。
- 帮助判断记录是应该清理，还是可以重新安装恢复。

#### **清理与重装**

- 支持批量选择无效插件。
- 支持从已安装插件列表中清理残留记录。
- 支持优先从本地插件源重新安装。
- 重新安装在后台执行，关闭插件页面后任务仍会继续。
- 显示逐插件进度、当前处理项和成功、跳过、失败统计。
- 区分本地源、在线源和无可用源；本地源优先，在线插件市场作为后备。
- 安装成功后自动热重载插件并刷新调度任务，无需重启 MoviePilot。
- 重新安装失败时保留原安装记录，避免误删。
- 清理和重装都不会主动删除目标插件的 MoviePilot 配置。

#### **Vue 界面**

- 配置页与详情页使用 Vue 联邦组件重做。
- 使用“清理记录”和“重新安装”两个一级 Tab 工作区。
- 适配桌面端侧栏导航和手机端底部 Tab 选择面板。
- 后台重装期间保留完整界面操作和关闭入口。

-------

## 配置解析

### 插件处理

1. **刷新扫描**：重新读取当前 MoviePilot 插件状态，找出无法加载的记录。
2. **清理记录**：从已安装插件列表中移除选中的无效记录，并清理异常运行目录；不会删除目标插件配置。
3. **重新安装**：任务提交后转入后台，优先从本地插件源重新安装，找不到时尝试插件市场；关闭页面不会停止任务。
4. **关闭页面**：退出插件详情页，手机端可通过底部按钮关闭。

### 使用建议

- 清理前先确认该插件已经不再使用。
- 插件配置会保留在 MoviePilot 配置中，例如 115 类插件已填写的参数不会因为“清理记录”被主动删除。
- 重新安装依赖本地插件源，找不到来源时不会强行删除原记录。
- 遇到市场缓存时，可先刷新插件市场或清理 MoviePilot 缓存。
