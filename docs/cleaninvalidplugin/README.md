# 清理无效插件

`CleanInvalidPlugin` 用于处理 MoviePilot 已安装插件列表中残留但无法加载的记录，支持扫描、清理和重新安装。

- 插件 ID：`CleanInvalidPlugin`
- 当前版本：`1.7`
- 插件目录：`cleaninvalidplugin`
- 适用版本：MoviePilot V3
- 作者：`shyblacktea`

## 工作流程

```text
扫描插件状态 → 识别无效记录 → 用户选择清理或重装 → 本地源优先、市场后备 → 后台执行并刷新状态
```

清理和重新安装是两个独立操作，清理不会主动删除目标插件的 MoviePilot 配置。

## 主要功能

### 无效插件扫描

- 扫描残留但无法加载的插件记录。
- 展示运行目录、本地插件源和异常状态。
- 区分可以清理的记录与仍可恢复的插件。

### 清理记录

- 支持选择并批量清理无效插件记录。
- 清理异常运行目录和安装状态。
- 不主动删除目标插件配置。

### 后台重新安装

- 优先从本地插件源重新安装。
- 找不到本地源时尝试在线插件市场。
- 后台任务显示当前处理项、进度和成功/跳过/失败统计。
- 页面关闭后任务继续运行，重新打开可查看进度。
- 同时只允许一个重装任务，避免重复安装。
- 安装成功后自动 reload 插件并刷新调度任务。
- 重装失败时保留原安装记录。

## 配置说明

插件主要通过 Vue 页面操作：

1. 点击刷新扫描，读取当前插件状态。
2. 在清理工作区选择确认无效的记录。
3. 在重新安装工作区选择目标并提交后台任务。
4. 根据来源标记确认使用本地源还是在线市场。
5. 查看完成、跳过和失败结果，必要时重新打开页面继续查看。

## 数据和安全边界

- 清理前应确认目标插件确实不再使用。
- 重新安装依赖可用的本地插件源或在线市场源。
- 插件不会因为重装失败而强行删除原记录。
- 插件配置与业务数据不应因清理记录被主动删除。
- 清理异常运行目录前应确认目录确实属于无效插件。
