# 手动订阅助手魔改版

## 更新日志

### 0.0.1

- 基于自动订阅助手改造成 MoviePilot V3 手动订阅工具。
- 抓取 Mikan 季番列表，支持当前季度或指定年份/季度。
- 尝试通过 Mikan 详情页关联 Bangumi，并继续识别 TMDB。
- 提供 Bangumi、TMDB 外链。
- 只有用户点击候选项的“创建订阅”按钮后才写入 MoviePilot，不运行后台自动订阅。
